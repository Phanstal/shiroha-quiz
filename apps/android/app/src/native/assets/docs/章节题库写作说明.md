# 章节题库写作说明

配套示例文件：`docs/章节题库模板.md`（可直接导入验证）。
本文只讲写法规则，不放进正式题库。

## 一、三层结构

```
# 第1章 章节名称        ← 章（一章一个，Markdown 的 # 可写可不写）
## 1.1 小节名称          ← 节（可省略，省略时整章算一个分区）
**试题1-【标签】**       ← 题目起点（必须能识别出题号）
题干
A. 选项
B. 选项
C. 选项
D. 选项
【答案】D
【解析】……
```

- 章标题：`第` + 数字 + `章` + 空格 + 章名，例如 `第1章 信息化发展`。
  数字支持阿拉伯数字和中文数字（`第一章`）。章名可自由写，建议全局唯一。
- 节标题：`数字.数字 标题`，例如 `1.1 信息与信息化`、`2.1.3 网络安全`。
  节标题会作为题目的“分区”保存，练习页可以按分区看题。
- 题号：每题必须有一个能被识别的题号开头。

## 二、题号的三种写法（任选其一）

1. `**试题1-【教材章节练习】**` —— 和原始 Word 最接近，推荐。
2. `试题1-【教材章节练习】` —— 不加粗也行。
3. `1. 题干……` —— 传统编号，不需要标签。

- `试题1-` 里的横线可有可无，`试题1` 也认。
- 方括号里的内容是**题目来源标签**，会存进题目的“来源”字段，不会混进题干。
  常见写法：`【教材章节练习】`、`【野人老师自编模拟题】`、`【历年真题】`。不写也可。
- 每章题号可以从 1 重新开始，系统按章节区分，不会互相覆盖，也不会误报重复题号。

## 三、选项写法

一行一个（最稳）：

```
A. 数据
B. 知识
C. 事实
D. 概念
```

全部挤在一行也支持，会自动拆开：

```
A. 数据  B. 知识  C. 事实  D. 概念
```

- 选项字母用大写 A–H。
- 判断题直接写 `A. 正确` / `B. 错误` 两行，会自动识别为判断题。

## 四、答案与解析

- `【答案】D`、`答案：D`、`正确答案：D` 都可以。
- 多选写 `【答案】ABD` 或 `【答案】A,B,D`。
- `【解析】……` 可以多段，一直写到下一题开始为止。
- 没有解析就直接省略 `【解析】` 行。
- 解析里出现“A 错”“B 错”这类选项指代不会误判成新题。

## 五、Markdown 相关的处理规则

- `#`、`##` 等标题井号会被自动去掉，所以可以直接把 Markdown 文件当题库导入。
- `**加粗**` 的星号会被自动去掉。
- 行内代码的反引号会被去掉。
- `___`（连续下划线）**不会**被当成 Markdown 处理，填空题横线可以照常写。

## 六、常见错误

| 错误写法 | 后果 | 正确写法 |
| --- | --- | --- |
| `1.1信息与信息化`（节号紧贴标题） | 可能被当成第 1 题 | `1.1 信息与信息化` |
| 题号写成 `试题一` | 识别不稳 | `试题1` |
| 选项写成 `A、数据` 且无题型分区 | 偶发误判 | `A. 数据` |
| 章标题写成 `第1章：信息化发展` | 章名会带上冒号 | `第1章 信息化发展` |
| 同一题内出现 `1.` 开头的分项说明 | 可能被切成两题 | 分项改用 `（1）` 或 `一是/二是` |

## 七、导入后怎么按章练

1. 导入完成 → 题库列表 → 打开这份题库。
2. 题库详情页出现「章节速练」卡片，列出每章题量，点「练这章」直接进入该章练习。
3. 也可以在练习页的「章节」筛选里切换：`全部章节` 按整本练，选某章只练该章。
4. 章节筛选会同时作用于「随机抽题」和「顺序刷题」；顺序刷题的进度按章节分别记录。
5. 章或节没写时不会报错，只是没有章节入口，全部题都归到「全部章节」。

## 八、给题库排版工具的清洗提示词

```
请把下面的题库整理成 Markdown，遵守以下规则：
1. 每章第一行写 `# 第N章 章名`，节写 `## N.M 节名`。
2. 每题以 `试题N-【来源标签】` 独占一行开头，N 在每章内从 1 连续编号。
3. 题干一句，选项每行一个，用 A. B. C. D. 开头。
4. 答案单独一行写 `【答案】X`，解析单独一行以 `【解析】` 开头。
5. 不要输出表格、不要输出 Markdown 代码块、不要加序号以外的装饰符号。
6. 原题里的题型标签（单选题/多选题/判断题）不需要保留在题干里。
```
